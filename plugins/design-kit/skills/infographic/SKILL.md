# Инфографика для маркетплейсов

Подготовка серии слайдов карточки товара до дизайна. Скилл общий для любого товара. Всё, что относится к конкретному проекту (цвета, шрифты, инструменты, правки), хранится в стайлгайде проекта, а не здесь.

Три шага по порядку. После каждого покажи Максиму результат и задай один вопрос: согласовать или что поменять. Следующий шаг только после согласования. Если Максим просит один шаг («сделай стайлгайд», «напиши промпты»), выполняй только его, опираясь на то, что уже есть в папке заказа.

Вводные (прочитай всё, что есть, не выдумывай недостающее): бриф или ТЗ заказчика, ссылка на товар, характеристики, фото товара, маркетплейс (по умолчанию WB), число слайдов, референсы и карточки конкурентов. Если не хватает того, без чего не начать (что за товар, главные характеристики), задай один короткий вопрос. Мелкие пробелы отмечай «уточнить у заказчика».

Файлы кладутся в папку заказа (или туда, куда скажет Максим): `план-инфографики.md`, `стайлгайд.md`, `промпты.md`.

## Шаг 1. План инфографики

**Что продаёт товар.**
- 3–5 главных качеств как выгода для покупателя («держит тепло 6 часов», а не «двойные стенки»).
- Возражения покупателя: что он проверит перед покупкой (размер, материал, комплектация, совместимость, уход).
- Только факты, которые подтверждает заказчик. Цифр, которых нет в брифе, не придумывай.

**Слайды.** Типовая серия на 6–8 слайдов, меняй под товар:
1. Обложка: товар крупно и 2–3 главных качества короткими словами, без технических цифр.
2. Главная выгода с картинкой, которая её доказывает.
3. Детали и материалы с выносками на товаре.
4. Размеры и характеристики: схема или товар рядом с понятным предметом для масштаба.
5. Сценарии: товар в жизни.
6. Варианты (цвета, модели, комплектации).
7. Комплектация, уход, гарантия, если это важно покупателю.

**Правила плана.**
- Один слайд, одна мысль. Ни одна цифра и ни один тезис не повторяются на двух слайдах.
- Цифры стоят там, где их объясняет картинка, и в том же порядке, что на картинке.
- Заголовок до 4–5 слов, тезис не длиннее строки колонки.
- Без превосходных степеней («лучший», «№1», «самый») и обещаний, которые товар не подтверждает.
- Технические зоны маркетплейса учитываются уже в плане. WB: 1200×1600, поля 60 px, справа сверху кнопки, слева снизу промо-зона (x < 540, y > 1430). Для других площадок проверь требования через поиск, если их нет в стайлгайде.

**Источник картинки** для каждого слайда: фото заказчика (какое, нужна ли вырезка, перекраска, апскейл), генерация (пометь «→ промпт», это вход шага 3) или графика в Figma (иконки, схема, таблица).

**Формат** `план-инфографики.md`:
```
# План инфографики: <товар>, <маркетплейс>, <N> слайдов

Главные качества: ...
Уточнить у заказчика: ...

## Слайд 1. Обложка
Мысль: ...
Заголовок: ...
Тезисы: ... / ... / ...
Визуал: ... (фото №2, вырезка | генерация → промпт | графика)
Композиция: товар справа по центру, текст слева, зоны WB свободны
```

## Шаг 2. Стайлгайд

Если в проекте уже есть `стайлгайд.md`, обнови его, а не создавай новый. Иначе создай по шаблону [references/styleguide-template.md](references/styleguide-template.md).

- Заполни под этот товар и заказчика: фон, акцентный цвет, шрифты, светотень, тени, стиль плашек и иконок. Цвета из фото товара, бренда заказчика и референсов, с HEX-кодами.
- Общие правила из шаблона (технические, содержание, композиция, товар на картинке) оставь: это опыт прошлых правок.
- Файл называется именно `стайлгайд.md`: по нему его находит агент `design-kit:card-reviewer`.
- Дальше в работе: если правка Максима повторяется или звучит как правило, предложи добавить её в стайлгайд одной строкой в нужный раздел. Правило пиши общим («текст не наезжает на товар»), а не про один слайд.

## Шаг 3. Промпты для генерации изображений

Для слайдов с пометкой «→ промпт» напиши промпты для другой модели по правилам [references/image-prompts.md](references/image-prompts.md). Сам изображения не генерируй, если Максим не попросит.

Главное:
- Модель генерирует фон, сцену или окружение. Сам товар обычно берётся с фото заказчика и вставляется в Figma: так он остаётся точным. Генерировать товар целиком только если Максим так решил, и тогда с референсом.
- Никакого текста на картинке: весь текст добавляется в Figma.
- Композиция повторяет план: где будет товар, где пустое место под текст, свободные зоны маркетплейса.
- Свет, ракурс и перспектива совпадают с фото товара, иначе тень и вставка не сойдутся.
- Цвета и настроение из стайлгайда.

Формат `промпты.md`: на каждый слайд краткая задача по-русски, промпт по-английски, негатив (если модель его поддерживает), параметры (соотношение сторон, референс), что сделать после генерации (кроп, апскейл, куда вставить товар).
