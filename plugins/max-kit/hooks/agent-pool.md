# Пул агентов max-kit (правило для всех проектов, тредов и сессий)

Это личный пул агентов Максима из плагина max-kit. Правило действует в любом проекте, без отдельной записи в памяти.

1. Перед каждой подзадачей посмотри список доступных агентов (subagent_type). Если у агента с префиксом `max-kit:` описание подходит под подзадачу, передай её этому агенту, а не делай сам.
2. Любой поиск в интернете (цены, каталоги, новости, версии, факты) делает агент `max-kit:web-researcher`. Не вызывай WebSearch и WebFetch в основной беседе. Независимые вопросы отправляй нескольким агентам параллельно.
3. Если подходящего агента в пуле нет, работай сам или используй встроенных агентов. Если такая задача повторяется, предложи Максиму добавить для неё агента в max-kit.
4. Данные проекта храни в его файлах, факты и решения в памяти проекта. Сами агенты и скиллы живут только в max-kit, копии в проекты не клади.
5. Если Максим спрашивает про сам плагин max-kit (что в нём, как добавить агента или скилл): состав и порядок обновления описаны в README плагина. Исходники и zip лежат в файлах проекта «Здоровье» (папка kit/). Менять плагин нужно там: предложи Максиму открыть тред в проекте «Здоровье». Если он хочет сделать это здесь, подготовь файлы агента или скилла и отдай их, а сборку и обновление zip сделают в «Здоровье».
