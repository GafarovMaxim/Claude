# usage-bar

Мод для Claude Desktop: полоса над окном ввода с тремя значениями: заполненность контекста, расход 5-часового лимита, расход недельного лимита.

Данные берутся из `session.measure` (контекст и окна `five_hour`, `seven_day`). Значение от 85% краснеет. Пока лимит не пришёл (нет подписки или ещё не было ответа), показывается «—».

Ограничение: мод может рисовать только полосу НАД окном ввода (`AbovePrompt`), ниже окна места для мода нет.

Установка (только по согласию Максима): положить папку в `~/.claude/dev-mods/<сессия>/usage-bar/` или подключить через `--plugin-dir`.

Проверка: `claude plugin validate mods/usage-bar` и `claude plugin test mods/usage-bar`.

Установка одной строкой в терминальной сессии Claude Code (после слияния PR):

```
/plugin install usage-bar --marketplace GafarovMaxim/Claude
```
