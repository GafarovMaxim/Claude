# usage-bar

Мод для Claude Desktop: строка под окном ввода с тремя значениями: заполненность контекста, расход 5-часового лимита, расход недельного лимита.

Значения читаются через `$.session.usage()` при каждой отрисовке подсказки под окном ввода (`PromptHint`, её рисуют терминал и Desktop). Значение от 85% помечается «!». Пока лимит не пришёл (нет подписки или ещё не было ответа), показывается «—». Подсказка заменяет стандартную строку подсказок под вводом.

Язык: берётся из настройки `language` в settings.json (иначе из LANG/LC_ALL): ru, en, de, fr, es, иначе английский. Язык интерфейса самого приложения мод узнать не может, только эту настройку.

На макете проверено, что подсказка рисуется на терминале и Desktop; в живом приложении мод ещё не видели.

Установка (только по согласию Максима): положить папку в `~/.claude/dev-mods/<сессия>/usage-bar/` или подключить через `--plugin-dir`.

Проверка: `claude plugin validate mods/usage-bar` и `claude plugin test mods/usage-bar`.

Установка одной строкой в терминальной сессии Claude Code (после слияния PR):

```
/plugin install usage-bar --marketplace GafarovMaxim/Claude
```
